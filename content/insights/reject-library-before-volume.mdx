Speed without a reject library is just faster guessing. Before the line ramps, photograph the units that almost pass — edge paint that is thin but legal, pad print that is soft but readable, carton crush that still ships.

Give each borderline a name and an owner. When the night shift has to choose, they should not invent a new standard. They should open the same folder you approved in daylight.
